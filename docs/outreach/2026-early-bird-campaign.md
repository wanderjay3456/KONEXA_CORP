# KONEXA 관리형 프로젝트 연락 운영

갱신: 2026-10-13 (KST). 이 문서는 종료된 2026-08-05 얼리버드 캠페인을 대체한다. 파일명은 기존 참조를 유지하기 위해 보존한다. 할인·가입 의무·인재 우선 열람 혜택은 현재 제안하지 않는다.

## 실제 상태

- 기존 Gmail 대화가 있는 더인벤션랩에 운영 준비 현황과 첫 실증 평가 기준을 묻는 후속 답장 1건을 예약했다. 예약 시각은 2026-10-13 09:10 KST / 00:10 UTC / 03:10 EEST. Gmail의 Scheduled 상태를 확인했다. 후속 확인에서 Gmail SENT와 2026-10-13 03:10:00+03:00 발송 시각을 확인했다. 첨부·참조 수신자는 없었다. 발송은 수신·회신·사업 합의의 증거가 아니다.
- 콴다, 모먼츠컴퍼니/비플레인, 위시컴퍼니, GPCLUB Vietnam의 개별 제안 4건을 KONEXA Gmail에 미발송 초안으로 저장했다. 수신동의 또는 적용 가능한 발송 근거가 확인되지 않아 예약하지 않았다. 초안의 서명·광고 표시·수신거부 경로 등도 실제 발송 전에 확정해야 한다.
- 2026-09-21 기존 외부 제안 이력이 있어 과거 문서의 외부 발송 0건 표시는 폐기한다. 회신 없는 발송 이력을 동의로 간주하지 않는다.
- BAT의 기존 발송은 차단되었다. Delivered Korea 관련 기존 메일은 다른 기업 주소로 잘못 지정되어 있었다. 자동 재발송·후속 발송에서 제외한다.
- 사이트는 공개 미리보기다. 개인정보 국외처리 고지와 가입·로그인의 긍정 경로 검증이 끝나기 전 회원가입이나 결제를 영업 행동 요청으로 사용하지 않는다.

## 현재 제안 기준

운영자는 대한민국의 유재영 개인이며 예비창업 단계다. 만 18세 이상 참여자를 대상으로 업무 범위 정리, 요건에 따른 후보 검토, 진행 점검과 결과 기록을 지원하는 관리형 프로젝트를 준비한다. 국가를 제한하지 않되 업무·언어·계약·결제 가능 여부를 개별 검토한다.

실제 수행 전 범위, 결과물, 검수 기준, 일정, 가격·통화·세금·수수료를 서면으로 협의한다. 미확인 인재풀·완료 고객 사례·매칭 정확도·매출 효과·채용/비자 업무 대행을 약속하지 않는다. 공개 파일럿의 외부 생성형 AI 분석은 끈 상태다.

## 발송 절차

1. 기존 대화의 목적과 상대방 요청을 먼저 읽고, 연락처·기업명·본문·첨부를 일치시킨다. 상대방의 결과 우선 요청을 소개 요청으로 바꾸지 않는다.
2. 신규 영업은 공식 기업 채널과 수신 근거를 함께 확인한다. 공개 이메일이나 과거 무응답은 광고 수신동의가 아니다. 채용·제품지원 전용 주소는 영업에 쓰지 않는다.
3. CSV의 consent_basis가 비어 있으면 신규 제안은 보류한다. 거절·차단·오발송 주소는 자동 후속 대상에서 제외한다. 근거 확인 후 광고 표기, 발신자 정보, 실제 작동하는 수신거부 경로 등 적용 요건을 갖춘다.
4. Gmail 기본 예약 기능을 사용한다. 화면 시간대를 읽고 KST를 변환한 뒤 Scheduled 상태를 확인한다. 로컬 컴퓨터가 켜져 있어야 하는 실행 계획을 Gmail 예약 완료라고 표현하지 않는다.
5. 전달 성공, 회신, 협의, 계약, 결과물 수락은 별도로 기록한다. 자동 반복 후속이나 추적 픽셀은 추가하지 않는다.

공식 기준: [정보통신망법 제50조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1030434423). 후보·제안 범위는 [기존 기업 검토 문서](2026-konexa-customer-prospects.md), 보류·경로 상태는 [기존 CSV](2026-early-bird-prospects.csv)를 참조한다. 담당자 비공개 대화와 상세 메일은 Gmail에만 보관한다.
